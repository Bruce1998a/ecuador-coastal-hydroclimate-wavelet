# Plataforma Científica y Monitor Climático Cantonal - Red E-OM Costa Ecuador

Plataforma web interactiva de acceso libre y código abierto para el monitoreo de precipitación y temperatura en los 85 cantones de la costa continental del Ecuador (1981–2026), basada en datos de reanálisis ERA5 y predicción meteorológica de Open-Meteo.

---

## 📊 Estructura de la Plataforma

* **Selector de Cantón:** Permite explorar cualquiera de los 85 cantones continentales de las provincias de Esmeraldas, Manabí, Santa Elena, Guayas, Los Ríos y El Oro.
* **Mapa de Estaciones:** Mapa interactivo con Leaflet que muestra la ubicación exacta de las estaciones virtuales `E-OM-001` a `E-OM-085`.
* **Pronóstico a 7 Días:** Conexión directa en tiempo real con la API de Open-Meteo para mostrar la probabilidad de lluvia, acumulación en mm y temperaturas esperadas.
* **Series Históricas (1981–2026):** Visualización interactiva conmutada en granularidad **Anual**, **Mensual** y **Diaria**.
* **Eventos El Niño (ENOS):** Resaltado visual de eventos extremos (1982-83, 1997-98, 2015-16, 2023-24) y el comportamiento del año 2026 actual.
* **Exportación de Datos:** Descarga de gráficas en alta resolución (PNG) y descarga de datos en formato CSV con un solo clic.
